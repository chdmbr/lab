# UMT 312L — class data pool

Static site for pooling across-group laboratory data, UMT 312L Mechanical Testing Lab,
Dept. of Materials Engineering, IISc. Autumn 2026.

Every one of the six experiments has an **ACTIVITY ACROSS DIFFERENT GROUPS** section in its
handout. Each group tests at one condition only, so nobody can complete that section alone.
This publishes Group 1 (Friday)'s measurements so the rest of the class can use them.

| file | what |
|---|---|
| `index.html` | what each lab needs from every group, and current status |
| `charpy.html` | Lab D — Charpy impact and Jominy end quench, full numbers |
| `hardness.html` | Lab F — live data-entry sheet; HB, HV and 95 % error bars compute as you type |
| `shared.css` | styling |

Raw measurements only — no report text. Plot it together, write your own report.

Served by GitHub Pages from `main`.
